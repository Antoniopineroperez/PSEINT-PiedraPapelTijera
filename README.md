# PSEINT-PiedraPapelTijera
Clasico juego de piedra, papel o tijera creado con pseudocodigo

# Reglas:
⛰️Piedra gana a ✂️tijeras
✂️Tijeras ganan a 📰papel
📰Papel gana a ⛰️piedra

En caso de ganar, perder o empatar, podrás elegir volver a jugar.

# Instrucciones:
Jugarás contra tu ordenador, elegirá una de las 3 opciones al azar.
La interfaz te pedirá que escribas tu elección
    PIEDRA | PAPEL | TIJERA
¡Y a jugar!
